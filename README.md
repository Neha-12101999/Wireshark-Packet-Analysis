#  Packet Analysis using Wireshark

## Objective
To capture and analyse network packets to understand communication between devices.

## Tools Used
- Wireshark

## Analysis Performed
- Captured live network traffic  
- Analysed HTTP and DNS packets   

## Filters Used
http
dns
tcp

## Findings
- Identified DNS queries and responses  
- Observed HTTP request/response cycle  
- Analysed packet structure and headers

## Note
All captures were performed on a local network. Sensitive data has been masked(like ip addr).
